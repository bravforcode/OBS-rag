## How to Create Each Agent

When you're ready to create a custom agent:

1. Say: **"Create a new agent"**
2. The Architect will ask you 6 questions:
   - **Name**: What should this agent be called?
   - **Purpose**: What does it do?
   - **Triggers**: When should it activate? (keywords the user might say)
   - **Tools**: What tools does it need? (Read, Write, Grep, etc.)
   - **Output**: What should it produce?
   - **Special**: Any special instructions or personality?

3. The agent file is created and auto-loaded in `.claude/agents/`
4. You can refine it anytime with "update my agent"
